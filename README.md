# Fun English for Kids — Ra'no Turg'unova

A responsive, static website for an English grammar and speaking tutor in Chilonzor, Tashkent.

## Preview locally
Open `index.html` in a web browser. An internet connection is needed for the Google Fonts and remote Unsplash photographs.

## Publish with GitHub + Vercel
1. Create a GitHub repository, for example `fun-english-for-kids`.
2. Upload `index.html`, `styles.css`, `script.js`, `README.md`, and the `assets` folder (including both Tashkent images). Keep the same folder structure.
3. In Vercel, choose **Add New → Project**, import the GitHub repository, and deploy it as a static site. No build command is needed; the output directory can be `.`.
4. Once deployed, Vercel gives you a live `*.vercel.app` URL.
5. Later, buy/connect your chosen domain in Vercel under **Project → Settings → Domains**, then follow the DNS records Vercel provides.
